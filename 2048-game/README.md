# 2048 小游戏

一款基于 HTML/CSS/JavaScript 开发的网页版 2048 游戏。

## 功能特性

### 🎮 基础游戏系统
- **计分系统**：实时显示当前分数，每次合成方块自动加分
- **最高分存储**：最高分保存在 localStorage，刷新不丢失
- **难度选择**：支持 4×4、5×5、6×6 三种网格大小
- **游戏控制**：开始/暂停/重新开始按钮，状态互斥

### 🎨 视觉与动效
- **主题皮肤**：浅色、深色、自然三套主题切换
- **动画效果**：方块出现、合并、得分飘字动画
- **音效系统**：移动、合并、胜利、失败音效

### 📱 进阶功能
- **触屏手势支持**：滑动屏幕控制移动
- **本地排行榜**：保存前10条最高成绩
- **操作回放**：游戏结束后可回放本局操作

## 操作方式

- **桌面端**：键盘方向键 ↑↓←→ 或 WASD
- **移动端**：滑动屏幕控制

## 运行方式

直接用浏览器打开 `index.html` 即可运行，无需任何依赖。

## 技术栈

- HTML5
- CSS3（CSS变量、动画）
- JavaScript（ES6+）
- Web Audio API（音效）
